# Pruebas Postman de credit-service

Este microservicio se prueba dentro de la colección consolidada del
proyecto (ver carpeta "3. Credit Service"), disponible aquí como copia de
referencia y también en `../../docs/postman/`. Ver ese README para
instrucciones completas de uso, orden de ejecución y casos de regla de
negocio cubiertos (crédito personal único activo, múltiples créditos
empresariales, límite disponible de tarjeta, etc.).
